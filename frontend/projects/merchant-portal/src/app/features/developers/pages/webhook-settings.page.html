Webhook settings

Get an HTTPS call on your server whenever a parcel is created or its status changes.

Always verify the signature

Anyone who knows your endpoint URL can send it fake events. Every real event carries an X-SwiftDrop-Signature header: the hex HMAC-SHA256 of timestamp + "." + body, keyed with your signing secret.

  1. Compute the HMAC over the raw request body (before any JSON parsing) with the secret, and compare it with the header using a constant-time comparison.
  2. Reject the event when X-SwiftDrop-Timestamp is more than 5 minutes old, to stop replays.
  3. Ignore an X-SwiftDrop-Event-Id you have already processed, and ignore updates whose occurredAt is older than the one you stored.
  4. Answer with a 2xx status within 5 seconds, and do slow work afterwards.

Ready-made verification code for Node.js, Python and Java is in the API documentation.
